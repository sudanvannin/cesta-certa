# Cesta Certa

Cardápio da semana e lista de compras com os preços de hoje do seu mercado. Grátis, sem cadastro.

**Abrir:** https://sudanvannin.github.io/cesta-certa/

Este repositório guarda só o site publicado (gerado automaticamente todo dia, com os preços coletados nos sites
de Super Nosso, Apoio Mineiro, Atacadão, Prezunic e Hortifruti). Os preços podem mudar no caixa. A Cesta Certa
não tem ligação com os mercados.
